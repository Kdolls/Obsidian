# LLM Wiki Core Setup Guide For Agents

## Captured source summary

The guide specifies a beginner-friendly Obsidian knowledge system that separates raw source notes from concise compiled Wiki notes. It requires traceable source links, generated catalogs and indexes, deterministic lint and health checks, source coverage tracking, and instructions for agents to search the compiled Wiki before opening broad source context. Its build plan covers folder structure, schemas and agent rules, note templates, Python standard-library tooling, a first source ingest, and query and lint checks. It says each compiled note should point to existing Raw sources and that unsupported claims and invented citations must be avoided.
