# Obsidian agent skills

## Summary

`kepano/obsidian-skills` is a collection of agent skills for Obsidian workflows and open file formats. The README lists skills for Obsidian Markdown, Bases, JSON Canvas, the Obsidian CLI, Defuddle, and Knap.

## Use

The repository says the skills follow the Agent Skills specification and work with compatible agents, including Codex. For Codex, its README describes copying the repository's `skills/` directory into the Codex skills path, typically `~/.codex/skills`. Check the repository for current installation details before installing.
