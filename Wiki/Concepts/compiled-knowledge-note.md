# Compiled knowledge note

## Summary

A compiled Wiki note turns useful material from one or more raw sources into concise, reusable knowledge. Its `sources` metadata should identify the Raw notes that support it, and `source_count` should match that list.

The Wiki catalog provides a compact search surface. Search it and read relevant compiled notes first; return to raw sources when more evidence or detail is needed.
